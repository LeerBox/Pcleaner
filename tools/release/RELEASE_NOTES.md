Let's get rid of ads.

PCleaner cleans temporary files and offers optional resets for website cookies,
tracking identifiers, and recent-file history. It does not block advertisements.

Download the **win-x64.zip** file, extract the whole archive, and run
**PCleaner.exe** on Windows 10 or Windows 11 (64-bit). The .NET runtime is included.
Keep the extracted files together. No installer is required.

Start with **Analyze**, review the results and side effects, then choose
**Clean now**. Website-data resets can sign you out. Session cleanup can remove
unsaved tabs. Back up important data before cleaning.

The accompanying `.sha256` file contains the ZIP's SHA-256 checksum. You can
compare it with `Get-FileHash .\PCleaner-*-win-x64.zip -Algorithm SHA256` in PowerShell.
The application is currently unsigned.
